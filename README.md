# AFTER HOURS — browser version

**Play: https://rob74752-hash.github.io/after-hours/**

A free, fan-made co-op and deathmatch shooter set in a natural history museum at night. This repository is the
browser build of the game (three.js); it runs on phones, tablets, Macs, Chromebooks, consoles and PCs.

- Accounts, friends, stats and live crossplay matches use the game's server at https://amnh.rob74752.workers.dev,
  so you can play together with people on the Windows app.
- Want the full Windows version (ray-traced lighting)? Download it from https://amnh.rob74752.workers.dev/#download

Not affiliated with, endorsed by or connected to the American Museum of Natural History or any other museum.
